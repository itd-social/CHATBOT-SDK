# Анкета с состояниями

Задайте `ITD_TOKEN`, `ITD_REFRESH_TOKEN` или `ITD_SESSION_PATH` ([настройки](../../docs/ENVIRONMENT.md)).
Запустите `python examples/fsm_bot/fsm_bot.py` из корня репозитория.
С другого аккаунта отправьте `/start`, имя, возраст и `да`; `/cancel` отменяет анкету.
Состояние сохраняется в `.fsm-state.json`, сообщения чата идут по очереди.
Ограничения повторов и хранилищ — в [руководстве FSM](../../docs/FSM.md).
