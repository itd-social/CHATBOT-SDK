# Участие в разработке

Спасибо за интерес к проекту. Начните с [настройки окружения и чеклиста](dev.md), затем прочитайте [правила веток и коммитов](GIT_WORKFLOW.md).

Для ошибки зарегистрируйте отдельный [Issue](https://github.com/itd-social/CHATBOT-SDK/issues), укажите версию Python и SDK, шаги воспроизведения, ожидаемый и фактический результат. Для новой возможности опишите задачу, API веб-клиента, на котором основано изменение, и возможные ограничения.

## Pre-commit

Хуки Ruff (`ruff check --fix` и `ruff format`) запускаются перед каждым коммитом:

```sh
python -m pip install -e ".[dev]"
pre-commit install
```

Вручную по всем файлам: `pre-commit run --all-files`; обновление версии хуков: `pre-commit autoupdate`. Версия хуков закреплена в `.pre-commit-config.yaml` и должна совпадать с `ruff` из `pyproject.toml`. Хуки не заменяют CI: job `lint` выполняет `ruff check` и `ruff format --check`.

Перед pull request запустите Ruff, pytest и сборку из `dev.md`. Добавьте тесты на существенное поведение и обновите документацию. Если проверяли изменение на ИТД, отдельно укажите, что именно проверено на живом сервере.

Не размещайте в issue, PR и логах JWT и refresh-токены, файлы сессий, cookie, личные сообщения и содержимое пользовательского бандла. Для проблем безопасности используйте [SECURITY.md](SECURITY.md).
