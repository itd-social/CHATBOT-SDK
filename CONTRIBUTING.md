# Участие в разработке

Спасибо, что хотите помочь! Вот с чего начать:

1. Подготовьте окружение и прочитайте чеклист: [dev.md](dev.md).
2. Узнайте правила веток и коммитов: [GIT_WORKFLOW.md](GIT_WORKFLOW.md).
3. Если меняете документацию, загляните в [правила написания](docs/WRITING_DOCS.md).

## Нашли ошибку или есть идея

Заведите [Issue](https://github.com/itd-social/CHATBOT-SDK/issues).

- **Ошибка:** версии Python и SDK, шаги воспроизведения, ожидаемый и фактический результат.
- **Новая возможность:** какая задача решается, на каком API веб-клиента основана идея и какие есть ограничения.

> **Осторожно.** Не размещайте в issue, PR и логах JWT, refresh-токены, файлы сессий, cookie, личные сообщения и содержимое пользовательского бандла. О проблемах безопасности пишите по [SECURITY.md](SECURITY.md).

## Pre-commit

Хуки Ruff (`ruff check --fix` и `ruff format`) запускаются перед каждым коммитом:

```sh
python -m pip install -e ".[dev]"
pre-commit install
```

Полезные команды:

- по всем файлам: `pre-commit run --all-files`;
- обновить версии хуков: `pre-commit autoupdate`.

Версия хуков закреплена в `.pre-commit-config.yaml` и должна совпадать с `ruff` из `pyproject.toml`. Хуки не заменяют CI: job `lint` выполняет `ruff check` и `ruff format --check`.

## Перед pull request

- Запустите Ruff, pytest и сборку из [dev.md](dev.md).
- Добавьте тесты на существенное поведение и обновите документацию.
- Если проверяли изменение на живом ИТД, напишите в PR, что именно.
